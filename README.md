# 本地 AI 对话（桌面端 · 自带聊天框）

一个**完全离线、数据不出本机**的 AI 聊天软件。后端用 [Ollama](https://ollama.com) 跑本地大模型，前端是 pywebview 内嵌的 HTML 聊天界面，可打包成单个 exe 双击运行。

支持：**多会话 + 历史记录持久化**、**流式打字机输出**、**Markdown 渲染（含代码块复制 + 轻量语法高亮）**、**一键拉取模型**、**停止生成 / 重新生成**、**温度等参数调节**、**本地知识库（RAG，离线、零额外依赖）**、**文件工具（表格分析 / 文档摘要 / 批量归档重命名，助力办公）**、**内置本地 AI（local-assistant，首次启动自动准备）**、**可随时修改「人设 / 上下文长度 / 思考强度」**。

### 可改的三项核心设置（设置面板）

- **AI 人设（系统提示词）**：定义 AI 的身份、语气与行为准则。留空则用默认「小墨」人设。
- **上下文长度（num_ctx）**：单次对话能记住的 token 数，默认 8192（复杂长文可上调）。
- **思考强度**：`关闭 / 轻 / 中 / 强` 四档。越高回答越严谨、越慢；复杂问题建议中/强。强度会实时注入到系统提示里，无需重建模型。

## 知识库（本地 RAG）

把你自己的资料（txt / md / 代码 / pdf / docx）导入后，开启「回答时参考知识库」，AI 就会优先依据这些资料作答，并在回答下方标注来源。

- 左下角「📚 知识库」→「选择文件导入」（用系统原生对话框选文件，支持多选）。
- 勾选「回答时参考知识库」即生效；取消勾选则回到纯模型回答。
- 资料**只在你本机索引**，不上传任何服务器；检索基于 SQLite FTS5 子串匹配，无需 embedding 模型，对中文友好。
- 数据位置：`data/knowledge.db`（与对话库同目录）。
- 说明：pdf / docx 需要先在本机装解析库（`pip install python-docx pypdf`），否则导入时会给出提示；纯文本与代码类无需任何额外依赖。

## 文件工具（办公）

左下角「🛠 文件工具」打开，内含两块：**表格分析** 与 **文件整理**。

### 表格分析
导入 CSV / XLSX，应用会解析出列统计（类型、空值、数值列的最值 / 均值）和前若干行预览，然后你可以针对这份表格提问（如「哪一列缺失值最多？」「给我一个按部门汇总的公式」），AI 会基于表格上下文作答。
- CSV 用标准库解析，零依赖；XLSX 需要 `openpyxl`（`pip install openpyxl`）。

### 文档摘要
在「📚 知识库」里每个文档右侧点「总结」，应用会让 AI 生成该文档的中文要点摘要（一次性返回，弹层查看）。适合快速消化长文档。

### 文件整理
选一个文件夹后：
- **按类型归档**：自动把图片 / 文档 / 表格 / 视频等分到同名子文件夹（「其他」类保持原位）。
- **批量重命名**：支持「序号模式（前缀 + 编号）」和「查找替换」，先预览新旧名对照，确认后再执行；执行前会校验目标是否冲突，不会覆盖已有文件。

以上操作均为本机文件系统行为，不上传任何数据。

## 环境要求

- Windows 10/11（已自带 WebView2）
- Python 3.11+（仅源码运行方式需要；打包后的 exe 自带运行环境）
- 内存：7B 模型建议 ≥16GB；3B 约 8GB 即可

> 你的显卡是 AMD Radeon Pro 5300M，没有 CUDA，Ollama 走 CPU 推理，速度约 3–5 字/秒（7B）。**首选 `qwen2.5:3b`**，质量与速度均衡。
>
> **关于 Ollama**：源码运行时需要本机装 Ollama；但打包后的 exe 会把 `ollama.exe` 一起打进包内，并自动创建 `local-assistant` 模型，首次启动只需联网下载一次基础模型（约 2GB），之后完全离线。

## 运行（源码方式）

```bat
pip install -r requirements.txt
python main.py
```

首次打开：
1. 若 Ollama 没启动，软件会自动拉起（优先用包内的 `ollama.exe`）。
2. 若没有 `local-assistant` 模型，软件会**自动联网拉取基础模型并创建**（首次约 2GB，顶部有进度提示，耐心等待）。
3. 模型就绪后右上角自动选中 `local-assistant`，直接发一句话即可。

> 想用自己单独装的 Ollama 也行：软件检测到系统已有 Ollama 时会优先连它，模型也存在系统默认的 `~/.ollama`。

## 打包成「自带 AI」的 exe

```bat
pip install pyinstaller
python build_exe.py
```

成品是一个文件夹 `dist/LocalAIChat/`，内含：

- `LocalAIChat.exe` —— 主程序，双击即开
- `ollama.exe` —— 内置的 Ollama 运行时（自动起服务）
- `Modelfile` —— 内置的「小墨」模型定义（含训练资料注入）
- `ui/` —— 界面资源
- `models/`（首次运行后自动生成）—— 内置模型就存这里

把这个文件夹整体复制给别人，对方**无需安装任何东西**即可使用本地 AI（首次运行需联网下载一次基础模型）。

## 数据存在哪

对话历史存在 SQLite，位置：

- 源码运行：`local-ai-chat/data/chat.db`
- 打包后：`%LOCALAPPDATA%\LocalAIChat\data\chat.db`
- 内置模型（打包且用包内 Ollama 时）：`dist\LocalAIChat\models\`（即程序目录下的 `models\`）

「设置」面板里点「数据目录」可一键打开。

## 常见问题

- **下载模型很慢 / 卡住**：取决于你的网到 Ollama 镜像的速度，与软件无关。可在 Ollama 官方设置镜像源后重试。
- **生成时卡顿**：CPU 推理正常现象。降低模型尺寸（用 3B 或 1.5B）、调小 `num_ctx`（如 4096）能明显提速。
- **想换默认模型**：下载多个后，在「设置」里选「默认模型」即可，顶栏也能临时切换。
- **清掉某段历史**：会话列表里鼠标悬停 → 删除；或「设置」面板清空全部。

## 项目结构

```
local-ai-chat/
├── main.py            # 入口（pywebview 窗口）
├── build_exe.py       # PyInstaller 打包（onedir + 内置 ollama/Modelfile）
├── requirements.txt
├── assets/
│   └── Modelfile      # 内置模型定义（自动打进 exe）
├── core/
│   ├── ollama.py      # Ollama HTTP 客户端（仅标准库，支持流式/拉取）
│   ├── store.py       # SQLite 会话与消息存储
│   ├── knowledge.py   # 本地知识库（FTS5 检索，零依赖 RAG）
│   ├── sheets.py      # 表格分析（CSV/xlsx 解析 + 统计 + 预览）
│   ├── automation.py  # 文件整理（归档 / 重命名，纯标准库）
│   └── api.py         # 暴露给前端的桥接层 + 流式推送 + 知识库/表格/自动化注入
└── ui/
    ├── index.html
    ├── styles.css
    ├── app.js         # 前端主逻辑（含知识库面板）
    └── markdown.js    # 零依赖 Markdown 渲染 + 轻量代码高亮
```
